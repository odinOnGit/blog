# Personal blog (React + Vite)

    npm install
    npm run dev        # local preview
    npm run build      # outputs /dist, deploy to Netlify, Vercel, GitHub Pages, etc.

**Write a post:** add `src/content/posts/my-post.md` (see hello-world.md for the header fields and formatting).
**Images and GIFs:** put in `public/images`, use `![caption](/images/name.jpg)`.
**Attachments:** put in `public/files`, list names in the post header: `attachments: report.pdf, data.zip`. PDFs, images, audio and video get a Preview button.
**Site name, tagline, about text, footer links:** `src/site.js`. Colours and fonts: top of `src/styles.css`.
